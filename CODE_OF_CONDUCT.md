# Code of Conduct

We welcome participants from all backgrounds. Treat others professionally, attribute contributions accurately and critique claims rather than people. Good-faith disagreement, negative results and rigorous scrutiny are encouraged.

Harassment, discrimination, threats, impersonation, plagiarism, fabricated evidence, deliberate misrepresentation and publication of private information without permission are unacceptable.

Report concerns privately to the repository maintainer through their available GitHub contact channels; avoid posting sensitive personal details in public issues. Maintainers may remove harmful content, limit participation or exclude contributors when necessary. Decisions should be proportionate and conflicts of interest disclosed. Good-faith scientific criticism is not misconduct.

These standards apply to repository interactions and activities represented as Open Research.
