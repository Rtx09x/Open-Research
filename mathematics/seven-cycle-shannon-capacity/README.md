# Seven-cycle Shannon capacity

## Question

How large can zero-error codes become for the seven-cycle confusability graph?

## Results and scope

The checkpoint contains exact finite constructions and several restricted-alphabet and finite-subgroup obstructions. The stated finite-subgroup bound of 367 applies only under its specified five-dimensional torus assumptions.
