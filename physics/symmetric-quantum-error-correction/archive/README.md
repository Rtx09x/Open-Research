# Source packages

[Source packages](source-packages/) contain supplementary historical proof notes, certificates and checkers. They are preserved for research traceability; their dated status does not supersede the current project README. Use a disposable extraction directory and inspect each package README before replay. The cubic-cut archive was repacked solely to remove Python bytecode caches; its scientific files are unchanged. `SHA256SUMS` records the released archive bytes. Third-party notices inside packages remain applicable.
